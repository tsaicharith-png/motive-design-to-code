# Motive

Motive is a browser-based code playground I built while practicing frontend development.

It lets me write HTML, CSS, and JavaScript separately and see the result directly in the browser.

## Features

- HTML, CSS, and JavaScript editors
- Run code and see the output
- Automatic saving using localStorage
- Character counters
- Tab indentation
- Run code using Ctrl + Enter
- Clear all code
- Download the project as an HTML file
- Light and dark mode
- Responsive layout

## Built With

- HTML
- CSS
- JavaScript

## How to Run

No installation is required.

Open `webpages/index.html` in a browser and start writing code.

## Version

### V1

This is the first version of Motive.

The goal of V1 was to build a working code playground using only HTML, CSS, and JavaScript.

More features will be added in future versions.
